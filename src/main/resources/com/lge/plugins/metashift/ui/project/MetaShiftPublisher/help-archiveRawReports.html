Keeps a copy of the report files generated by the meta-shift layer (the gcovr coverage pages, the sentinel mutation testing pages and the gtest unit test pages, together with the stylesheets and images they reference) with each build, so they can be viewed and downloaded from the recipe page without the HTML Publisher plugin or a Resource Root URL.

Uncheck this to save disk space on the controller. The parsed metrics, charts and tables are unaffected; only the Raw report links disappear for builds published while the option is off.

Files larger than 10 MB are never archived, and each one is named in the build log.
