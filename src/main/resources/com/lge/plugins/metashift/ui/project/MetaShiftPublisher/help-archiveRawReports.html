Keeps a copy of the report files generated by the meta-shift layer (the gcovr coverage pages, the sentinel mutation testing pages and the gtest unit test pages, together with the stylesheets and images they reference) with each build, and offers them as a single raw report (.zip) download on each recipe page. The pages are handed out rather than served, so nothing renders them inside Jenkins and neither the HTML Publisher plugin nor a Resource Root URL is involved.

Uncheck this to save disk space on the controller. The parsed metrics, charts and tables are unaffected; only the raw report (.zip) links disappear for builds published while the option is off.

The whole report directory is copied, with no size limit of its own. The build log reports how many files were archived and how much space they take.

Archiving is best-effort: a failure is logged as a warning and never fails the build, it only leaves that build without its download links.
